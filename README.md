# Lorenzo’s Portfolio

Prima prova desktop di un portfolio su una lavagna. L’ingresso mostra l’ufficio. Con lo scroll ci si avvicina e scegliendo un titolo si inquadra il primo foglio della sezione.

Apri `index.html` in un browser per vedere la prova. È una pagina statica con font e immagine salvati nella repo.

- `index.html` contiene i titoli e i fogli provvisori.
- `styles.css` definisce la tipografia, i colori e le posizioni sulla lavagna.
- `board.js` gestisce l’inquadratura e lo zoom.
- `assets/` contiene l’ufficio con la lavagna e i font Caveat Brush e Kalam con le rispettive licenze SIL Open Font License.

Per collegare una repo GitHub vuota, copia il suo URL HTTPS, sostituiscilo a `URL_DELLA_REPO` ed esegui questi comandi da questa cartella.

```sh
git remote add origin URL_DELLA_REPO
git push -u origin main
```
